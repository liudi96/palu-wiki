# 🚀 Palu Wiki 腾讯云部署实战计划

## 📊 项目状态概览
- **起始状态**: 本地开发完成95%，AI功能已修复，核心功能验证可用
- **目标状态**: 成功部署到腾讯云香港服务器，供朋友试用，获得全栈部署实战经验
- **预计时间**: 5-7天
- **学习重点**: 云服务器部署、Docker容器化、CI/CD流程、基础运维

---

## 🔥 阶段一：本地环境完善和测试 (1-2天)

- [ ] **完整测试所有核心功能**：启动完整应用(./start.sh)，测试用户注册登录、文章创建编辑、AI生成、管理后台、文件上传等所有功能，记录发现的bug并修复

- [ ] **创建生产环境配置**：复制.env为.env.production，修改数据库连接为生产环境配置(使用环境变量)，设置强JWT密钥，配置域名相关设置

- [ ] **优化Docker配置**：检查docker-compose.yml和Dockerfile，确保适合生产环境，添加健康检查，配置重启策略，优化镜像大小

- [ ] **建立基础监控**：添加应用日志输出，配置错误日志收集，添加基本的性能监控端点(/metrics)，准备数据库备份脚本

- [ ] **安全加固配置**：更新所有默认密码，配置CORS限制，添加请求频率限制中间件，设置安全响应头，检查API输入验证

---

## 🌐 阶段二：腾讯云服务器准备 (1天)

- [ ] **服务器基础配置**：登录腾讯云服务器，更新系统包(apt update && apt upgrade)，配置防火墙(ufw)开放必要端口(22,80,443,8080,3001)，创建非root用户

- [ ] **安装必要软件**：安装Docker和Docker Compose，安装Git，配置SSH密钥认证，安装nginx作为反向代理，安装certbot用于SSL证书

- [ ] **域名和SSL配置**：如果有域名则配置DNS解析到服务器IP，申请Let's Encrypt SSL证书，配置nginx反向代理到应用端口，测试HTTPS访问

- [ ] **数据库环境搭建**：使用Docker部署PostgreSQL，创建数据库用户和权限，导入本地数据库结构，配置数据库连接安全策略

- [ ] **服务器安全配置**：禁用root登录，配置SSH密钥只允许，设置fail2ban防暴力破解，配置自动安全更新，设置系统监控告警

---

## 🚢 阶段三：应用部署 (1-2天)

- [ ] **代码部署**：将代码推送到GitHub(如果还没有)，在服务器上clone代码仓库，配置生产环境变量文件，构建Docker镜像

- [ ] **数据库初始化**：运行数据库迁移脚本，创建默认分类和管理员用户，导入测试数据(可选)，验证数据库连接和功能

- [ ] **应用启动测试**：使用docker-compose启动所有服务，检查容器状态和日志，测试数据库连接，验证AI功能是否正常

- [ ] **反向代理配置**：配置nginx将域名/IP流量代理到应用容器，配置静态文件服务(uploads目录)，设置gzip压缩和缓存策略

- [ ] **端到端功能测试**：通过外网访问测试所有功能，测试用户注册登录流程，测试文章创建和AI生成，测试文件上传，记录并修复发现的问题

---

## ⚙️ 阶段四：CI/CD和自动化 (1天)

- [ ] **建立GitHub Actions工作流**：创建.github/workflows/deploy.yml，配置自动部署到服务器，设置环境变量和密钥管理，配置部署后的健康检查

- [ ] **创建部署脚本**：编写deploy.sh脚本自动拉取代码、构建镜像、更新服务，创建backup.sh脚本自动备份数据库，创建monitor.sh脚本检查服务状态

- [ ] **测试自动部署**：推送代码到main分支触发自动部署，验证部署流程的完整性，测试部署后应用的可用性，优化部署速度和稳定性

- [ ] **配置监控告警**：设置服务器资源监控(CPU、内存、磁盘)，配置应用日志监控，设置关键服务异常告警，测试告警机制是否工作

---

## 🔧 阶段五：优化和维护 (持续)

- [ ] **性能优化**：分析应用性能瓶颈，配置Redis缓存(如需要)，优化数据库查询，配置CDN加速静态资源，压力测试验证性能

- [ ] **用户体验优化**：收集朋友们的使用反馈，修复用户体验问题，添加更多实用功能，优化移动端适配，完善错误提示信息

- [ ] **建立运维流程**：制定定期备份策略，建立日志分析流程，制定故障恢复预案，设置定期安全更新流程，记录运维操作文档

- [ ] **项目总结和文档**：总结部署过程中的经验教训，更新项目README和部署文档，记录遇到的坑和解决方案，分享给社区或朋友
