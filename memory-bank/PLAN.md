# 🚀 Palu Wiki Go + Python混合AI系统开发计划

## 🎯 Phase 1: AI微服务分离和gRPC通信 (2-3周)

### 🔧 1.1 Python AI微服务基础搭建 (3-4天)
- [ ] **创建AI服务项目结构**
  ```
  ai-service/
  ├── app/
  │   ├── main.py           # FastAPI应用入口
  │   ├── services/         # AI服务逻辑
  │   ├── models/          # 数据模型
  │   └── utils/           # 工具函数
  ├── protos/              # gRPC协议定义
  ├── requirements.txt     # Python依赖
  └── Dockerfile          # 容器配置
  ```

- [ ] **FastAPI基础框架搭建**：创建健康检查端点，配置日志系统，添加中间件支持，集成异步处理

- [ ] **LangChain框架集成**：安装LangChain核心库，配置多模型支持，实现基础的AI对话接口，添加错误处理机制

- [ ] **AI模型接入和测试**：集成DeepSeek API，配置通义千问备用，保留星火AI兜底，实现智能降级策略

### 🔌 1.2 gRPC服务间通信建立 (2-3天)
- [ ] **Protocol Buffer接口设计**
  ```protobuf
  service AIService {
    rpc GenerateContent(ContentRequest) returns (ContentResponse);
    rpc GenerateArticle(ArticleRequest) returns (ArticleResponse);
    rpc SearchSimilar(SearchRequest) returns (SearchResponse);
    rpc GetProviderStats(StatsRequest) returns (StatsResponse);
  }
  ```

- [ ] **生成gRPC代码**：为Go和Python生成gRPC客户端/服务端代码，配置代码生成脚本，集成到构建流程

- [ ] **Go客户端改造**：将现有AI Manager改为gRPC客户端，保持原有接口不变，添加连接池和重试机制，实现优雅降级

- [ ] **Python服务端实现**：实现gRPC服务接口，集成AI模型调用，添加请求验证和限流，配置并发处理

### 🔍 1.3 向量数据库和RAG系统 (4-5天)
- [ ] **ChromaDB集成**：安装和配置ChromaDB，设计文档存储结构，实现向量化处理流程，配置持久化存储

- [ ] **文档预处理系统**：实现文本分块算法，配置向量嵌入模型，建立文档更新流程，添加重复检测

- [ ] **RAG检索系统构建**：实现相似度搜索，构建上下文组装逻辑，优化检索相关性，添加结果过滤

- [ ] **知识库管理接口**：提供文档增删改查API，实现批量导入功能，添加知识库统计，配置搜索优化

### ✅ 1.4 系统集成测试和优化 (2-3天)
- [ ] **端到端功能测试**：测试AI生成功能完整性，验证gRPC通信稳定性，检查错误处理机制，确认性能指标

- [ ] **Docker容器化整合**：更新docker-compose配置，添加AI服务容器，配置服务依赖关系，优化启动顺序

- [ ] **监控和日志系统**：集成服务监控，添加性能指标收集，配置错误告警，建立日志聚合
